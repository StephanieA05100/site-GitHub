Chargement du fichier de consignes

Ouvrir le fichier pdf en suivant le lien : Fiche élève
Lisez attentivement la fiche. Vous ne pourrez pas compléter le tableau : notez les codes sur un brouillon


Hackeur 1

1) Enregistrer le fichier suivant dans votre répertoire perso "enregistrer la cible du lien sous" : Hackeur 1

2) Ouvrir l'application Spyder puis ouvrir le fichier Hackeur1 depuis l'application.

3) Suivre les consignes de la fiche élève :

  • exécuter le fichier (flèche verte dans le bandeau du haut)
  • dans la fenêtre en bas à gauche, appeler les fonctions une à une cracker 1(...) en choisissant les nons paramètres
  • noter les codes obtenus sur un brouillon
  • attention ne pas re-exéuter le fichier encours de route ou vous devrez tout recommencer !
  • faire valider le code final au professeur
