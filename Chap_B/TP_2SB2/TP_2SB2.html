Simulation Filius : réseau 1 - relier deux ordinateurs

Ouvrir le logiciel Filius

Filius permet de construire un réseau (icône marteau grisée), puis de l'utiliser (icône flèche verte grisée)

Pour la construction d'un réseau simple et sa vérification, regardez attentivement la vidéo ci-dessous, jusqu'au temps 02 :15

Application : réalisez dans Filius un réseau composé de deux portables P1 et P2, reliés entre eux par un câble. Le portable P1 aura pour adresse IP 192.1.1.1 et P2 aura pour adresse IP 192.1.1.2

Testez la connexion (ping depuis l'un des portables) puis copiez le fichier sur le réseau du lycée dans le répertoire classe "travail". Votre fichier devra être nommé en respectant le format : Réseau1-NOM
