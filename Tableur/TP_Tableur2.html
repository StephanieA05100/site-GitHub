TP tableur 2 - Construire des diagrammes
Stéphanie Ader
Lycée de la Plaine de l'Ain


L'objectif de ce TP est d'utiliser un tableur pour construire divers diagrammes.


Charger le fichier ci-dessous, l'enregistrer dans votre dossier personnel (clic droit et "enregistrer la cible du lien sous") et l'ouvrir dans libroffice. Fichier Tableur 2

Pour les onglets 1 à 4, un diagramme a été fait pour le tableau violet, vous devez faire un diagramme de même type avec les données du tableau orange.
N'oubliez pas de mettre un titre à votre diagramme, ainsi que des titres aux axes le cas échéant.
Faire valider au professeur chaque diagramme.

Quelques indications pour vous aider :

  • Pour insérer un diagramme, sélectionnez les cellules contenant les données (y compris les entêtes), puis aller dans insertion / diagramme
  • Pour formater les axes, double-cliquez sur le diagramme puis clic droit au niveau de l'axe et choisissez "Formater l'axe"
  • Onglet 1 : pour avoir les étiquettes de données à l'extérieur du diagramme, vous devez faire un clic droit sur le diagramme pour insérer des étiquettes de données, puis formater ces étiquettes.
  • Onglet 4 : choisissez le diagramme "XY dispersion"

Pour l'onglet 5, vous devez choisir le diagramme le plus adéquat pour chacune des quatre séries de données.
