1. LES DONNEES

Définition

Une donnée est une valeur ou un ensemble de valeurs pouvant prendre plusieurs formes (nombre, chaîne de caractères …) et permettant de décrire un ou plusieurs objets.
Exemple : pour un élève de votre classe, l’âge est une donnée, le prénom, la photo …

Les données constituent la matière première de toute activité numérique.

Afin de permettre leur utilisation, il est nécessaire de :

  • Les conserver de manière persistante.
  • Les structurer correctement pour que l'on puisse les exploiter facilement pour produire de l'information.

Le Big Data

Le Big Data est l’ensemble des données numériques produites par l’utilisation des nouvelles technologies ou l’échange d’informations.

Quelques faits impressionnants sur le Big Data – source lebigdata.fr :

  • 1,7 megaoctets de données créés chaque seconde par chaque personne en 2024
  • 463 exaoctets sont créées par jour (source findstack.fr), soit 1.000.000.000.000.000 octets
  • Pour télécharger l’intégralité des données présentes sur Internet, il faudrait plus de 180 millions d’années à un individu.
  • Le volume de données mondiales double tous les trois ans
  • 90% des données mondiales ont été créées au cours des dix dernières années – info 2021
  • 6 millions de développeurs travaillent sur des outils Big Data

   

En quoi le Big Data améliore-t-il nos vies quotidiennes ? Source : vouchercould.fr

  • Soins médicaux : prévoir les pics de maladies, identifier les personnes à risque
  • Santé : suivi actif ou passif
  • Transports urbains : systèmes GPS pour suivre les transports publics
  • Gestion des déchets : capteurs dans les containeurs, historique de l’utilisation
  • Pompiers : systèmes de surveillance, géolocalisation des véhicules d’urgence, détecteurs de fumée
  • Prévision et compréhension du crime : analyse des zones notamment
  • …


Le Big Data – les 3V

Le Big Data répond à 3 principes, résumés par les « trois V » de l’analyste Doug Laney :

  • Le Volume de données
  • La Variété des données
  • La Vélocité

On y ajoute maintenant :

  • La Véracité : la qualité des analyses se fait à partir de la qualité de la donnée.
  • La Variabilité : les données évoluent dans le temps. Leur qualité peut se détériorer.
  • La Valeur 


Les formats de données

Le format des données correspond à la manière dont celles-ci sont codées.


L’Open Data

Les Open Data, ou données ouvertes, sont des données auxquelles l’accès est totalement public et libre de droit, de même que leur exploitation ou leur réutilisation.

Exemple d’Open Data : data.gouv.fr


Les métadonnées

Les métadonnées d’un fichier sont un ensemble de données décrivant les caractéristiques d’un fichier, sans être spécifiquement liées à son contenu.
Ce sont donc les informations qui décrivent un fichier.
Par exemple : nom, date de création, format, créateur …

3. LES DONNEES PERSONNELLES

Définition de la CNIL :

Une donnée personnelle est toute information se rapportant à une personne physique identifiée ou identifiable. Une personne physique peut être identifiée :

  • directement (exemple : nom et prénom) ;
  • indirectement (exemple : par un numéro de téléphone ou de plaque d’immatriculation, un identifiant tel que le numéro de sécurité sociale, une adresse postale ou courriel, mais aussi la voix ou l’image).

L’identification d’une personne physique peut être réalisée :

  • à partir d’une seule donnée (exempleC: nom) ;
  • à partir du croisement d’un ensemble de données (exemple : une femme vivant à telle adresse, née tel jour et membre dans telle association).

La protection des données personnelles

Tous les états membres de l’UE sont dotés d’une loi informatique et libertés et d’une autorité nationale de protection des données.

Les données sont protégées par :

  • La loi informatique, fichiers et libertés
  • Le RGPD, Règlement Général sur la Protection des Données entré en vigueur en mai 2018

En France, l’autorité compétente est la CNIL (Commission Nationale de l’Informatique et des Libertés), créée en 1978.

4. LE STOCKAGE DES DONNEES

Le cloud

On peut stocker des données localement (clef USB, disque dur, CD …) ou en externe sur un Cloud.
Le cloud computing consiste à utiliser un serveur externe pour stocker des données, ou encore utiliser la puissance de celui-ci pour se servir d’un logiciel. A titre d’exemple, si vous avez déjà eu recours à des services tels que Dropbox, Google Drive ou encore l’iCloud d’Apple, alors vous êtes un utilisateur du cloud computing.
Même l’utilisation d’une adresse mail constitue une utilisation du cloud, les données étant sur un serveur et pas chez vous.

Les avantages du cloud pour les entreprises :

  • Les données sont accessibles à tous, en temps réel, et dans la dernière version
  • Pas de perte d’information en cas d’incendie, d’inondation …
  • Les employés peuvent travailler de n’importe où
  • Les données sont mieux sécurisées
  • Les applications sont mises à jour automatiquement
  • Réduire les coûts (moins de matériel)
  • Le service informatique de l’entreprise est allégé

Les avantages du cloud pour les particuliers :

  • Les données peuvent être partagées facilement
  • Pas de perte de donnée en cas de vol, d’incendie …
  • Meilleure sécurité des données
  • Moins de coût de matériel

Les inconvénients du cloud :

  • Les données hébergées sur des serveurs virtuels sont sous le contrôle du fournisseur de services de cloud computing
  • Si le cloud est détenu par une entreprise US, les données peuvent être saisies dans le cadre de la lutte anti terrorisme
  • Les problèmes techniques peuvent être réglés uniquement par le fournisseur
  • Les services de stockage de données sont des cibles privilégiées pour les hackeurs
  • L’accès aux données ne peut se faire qu’en ligne : pas d’accès en cas de panne de réseau
  • L’accès des données en ligne uniquement engendre une pollution importante

Les data centers

En pratique, les données stockées dans le cloud le sont dans des data centers.


>

Données 2025 : source techjury.net

  • Environ 12 259 data centers à travers le monde en 2026, dont 4 011 aux États-Unis et 344 en France; Nota : en 2022 il y avait 8 000 data centers.
  • Les data centers utilisaient 2,7% de l'électricité mondiale en 2025
  • Surface moyenne : 9 300 m² ; le plus grand se situe à Hohhot en Chine, pour China Telecom et couvre une surface de 994 000 m², soit l’équivalent d’un carré de 1 km de côté

Impact environnemental des data centers en France: source Ademe

  • Les données doivent être accessibles en permanence, les serveurs doivent donc être allumés et refroidis 7j/7, 24h/24.
  • Un data center moyen consomme autant d’électricité qu’une ville de 40 000 habitants
  • Le numérique consomme 11 % de la production électrique Française en 2025.
  • Les data centers représentent à eux seuls 2,2 % de la consommation électrique annuelle, soit l’équivalent de l’électricité consommée par 9 à 10 agglomérations de plus de 100 000 habitants pendant un an
  • Si rien n'est fait, la consommation pourrait être multipliée par 3,7 d’ici 2035
  • Les data centers représentent 2% de l’empreinte carbone française en 2022 (46% des 4,4% du numérique).
  • Si rien n'est fait l'Ademe s'attend à un triplement des émissions de gaz à effet de serre d'ici 2050. Et encore ! l'étude publiée ne comprend pas encore les impats de l'IA générative
