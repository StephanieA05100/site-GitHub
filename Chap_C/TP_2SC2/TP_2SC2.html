I - Modifier un fichier html

Description du html et du css

1) Lire attentivement l'activité 3 P 62/63

2) Si besoin : lire le cours et visionner les vidéos de l'université de Lille, parties 4.1, 4.2, 4.3 en suivant le lien : Lille


Chargement et exécution du fichier

1) Dans votre dossier perso (prenom.nom), créez un sous-dossier "chamois".

2) Dans ce sous-dossier, enregistrer les deux fichiers suivants en faisant clic droit et "enregistrer la cible du lien sous" : Chamois html et Chamois jpeg

3) Renommez le fichier html en utilisant la convention : Chamois1 - NOM - Prénom.html

4) A partir de votre sous-dossier, ouvrez le fichier html dans Mozilla Firefox : observez les styles, le titre de la page, le titre affiché dans l'onglet ...

5) Ouvrez le fichier html dans notepad++ ou Geany : le code html apparaît. Repérez le titre de l'onglet et le titre qui apparaît en haut de la page.

Nous allons modifier le fichier html. Les modifications se font sur NotePad++ ou Geany. Après chaque modification, enregistrez le fichier et rafraîchissez la fenêtre de Firefox pour voir apparaître les modifications.


Modifier le contenu

1) Sur NotePad++ ou Geany, repérez le titre de l'onglet et le titre qui apparaît en haut de la page.
Corrigez la faute d'orthographe qui apparaît dans le titre de l'onglet.

2) Repérez, ligne 22, le code permettant d'afficher l'image.
Modifiez la taille de l'image pour passer sa largeur à 300 px

3) Observez, ligne 67, le lien hypertexte vers le site externe (adresse du site, texte qui apparaît dans la page).
Ajoutez, en utilisant le même format, une deuxième source : https://www.instinct-animal.fr/chamois/. Le texte à cliquer doit être "instinct-animal.fr"

4) Observez bien la liste à puces et ajoutez un prédateur : le lynx

5) Le texte wikipédia est trop compact : après avoir observé l'utilisation des balises p et /p, créez des paragraphes (un pour chaque élément en gras)

6) Sur le site ecologie.nature.free.fr, page dédiée au chamois, accédez au code source (clic droit puis "code source de la page").
Observez le et copiez la partie qui correspond au tableau. Collez la dans votre fichier html, après les sources, sous la ligne "Résumé"

7) Ajouter une ligne dans le tableau, indiquant l'habitat du chamois : Zones montagneuses d'Europe et d'Asie


Modifier le style

1) Sur la partie "head" de votre fichier html, observez la ligne 8 : elle définit le style du titre "h1".

2) Dans la partie "head", en dessous du style h1, créez le style "h6", en suivant le modèle de "h1" (mais vous ne devez pas effacer ou changer h1) ; il aura les propriétés suivantes :

  • texte en rouge
  • texte en gras (font-weight :900) et centré (text-align :center)
  • police (font-family en html) en : Monotype Corsiva, cursive
  • taille de police 24px

3) En dessous du titre général (Présentation du chamois), créez un sous titre contenant vos nom et prénom

4) Affectez ce style "h6" au sous titre contenant vos noms (s'inspirer du titre général auquel est affectée le style h1)


Remise du travail

Rendre votre fichier html dans l'ENT, devoirs à faire du jour, Chamois 1



II - Créer et associer un fichier CSS

Associer un fichier CSS existant

Au préalable, copiez et collez votre fichier html, et changer de nom : Chamois2 - NOM - Prénom.html. Vous travaillerez dorénavant avec ce fichier, pour ne pas modifier le précédent.

1) Chargez le fichier css dans votre sous-dossier "Chamois" : CSS

2) Renommez le fichier css en utilisant le format : css_NOM_Prénom.css

3) Ouvrez ce fichier avec notepad++ ou Geany

4) Dans votre fichier html, remplacez la ligne 8 (celle qui définit le style du titre h1) par : en modifiant le nom du fichier css

5) Testez - vérifiez que le titre du haut est maintenant au milieu de la page


Ajouter un style présent dans le css

Mettre les sous-titres du document ("Généralités", "Photo", "Prédateurs", "Extraits de la page Wikipédia dédiée au chamois", "Pour en savoir plus", "Résumé") entre des balises h2 et /h2.
Observez : que se passe-t-il ?


Modifier le fichier CSS

Apportez les modifications nécessaires au fichier CSS pour que :

  • le fond du document soit bleu
  • la police utilisée pour tout le document, sauf le tableau, soit URW Chancery L, cursive
  • tout soit écrit en blanc, sauf les titres h1, h2 ...
  • une marge à gauche de 20 px existe sur tout le document
  • le titre général h1 apparaisse en jaune et soit souligné (vous pouvez effectuer une recherche sur internet)
  • le style h2 utilisé pour les sous-titres apparaisse en bleu turquoise (chercher le code hexa sur internet)

Remise du travail

Rendre votre fichier html et votre fichier css dans l'ENT, devoirs à faire du jour, Chamois 2

III - Travail en groupe : réaliser une page web

Travail sur 2 séances à finir à la maison et à rendre 2 semaines plus tard

Par groupe de 2 élèves, choisissez un thème parmi ceux ci-dessous et faites une page web sur ce thème.

  • un thème lié à la SNT, si possible un thème d'actualité
  • la présentation d'un personnage scientifique connu dans le monde de l'informatique
  • orientation : présentation d'un métier et d'un cursus pour y parvenir

Les contraintes sont les suivantes :

  • vous devrez remettre un sous-dossier contenant au minimum un fichier html et un fichier CSS
  • la page doit comporter au moins une image
  • la page doit comporter au moins un tableau
  • la page doit comporter au moins un lien vers un site externe
  • la page doit comporter au moins trois styles différents
  • le travail devra être personnel, le contenu sera pris en compte
  • les sources (des photos, des données) doivent être citées

Vous pouvez repartir du fichier "chamois" pour vous aider, notamment pour l'entête, mais vous devez ensuite vous en détacher : la forme sera notée plus que le fond et ce sont les modifications sur la forme qui vous rapporteront des points.

Ce travail sera enregistré et fourni au professeur sur clef USB : fournissez bien toutes les données nécessaires (fichier html, css et images).
