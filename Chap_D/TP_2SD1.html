Lycée de la Plaine de l'Ain

La bibliothèque PILLOW de Python permet de travailler sur des photos. Nous l'utiliserons sur les 3 prochains TP

1) Charger le fichier ci-dessous, l'enregistrer dans votre dossier personnel (clic droit et "enregistrer la cible du lien sous") et l'ouvrir à partir de Spyder.
Fichier Python
2) Lire les instructions et les commentaires et essayer de comprendre ce que fera le programme
3) Trouver une photo au format jpeg, de préférence pas trop grosse, et l'enregistrer dans le même sous-dossier que votre fichier Python
4) Faire les modifications nécessaires pour que le programme Python travaille à partir de votre photo, puis lancer le programme et observer le résultat dans l'explorateur Windows (le programme crée des fichiers dans le même sous dossier, observez leur taille et ce qu'il se passe quand vous zoomez)
5) Finir le programme en divisant les dimensions de votre photo par 10 puis par 20
6) Faire valider au professeur
